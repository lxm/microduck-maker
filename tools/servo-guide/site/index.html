01 / FIND

找到你手上的组件

按左腿、右腿或头颈筛选。切换正面、背面和侧面，用透明模式看清内部。

02 / IDENTIFY

点编号，定位舵机

点击列表、模型或标签，查看高亮位置、中文名称及所属组件。左右按机器人自身定义。

03 / CHECK

贴好标签，再勾选

逐颗核对已写入的 ID。安装勾选保存在当前浏览器，也可以导出 CSV 编号表。

开始前，分清这几件事。

模型上的姿态，就是舵机零位吗？

不是。3D 页面保留的是 CAD 装配姿态，用于辨认安装位置和编号，不能直接作为归零或站立姿态。本工具不提供运动控制、批量校零或站立指令。

能给舵机写入 ID 吗？

不能。这是查看工具，不读取串口，也不知道实机上写了什么 ID。请通过兼容 HD-1910 的独立调试工具逐颗确认，再按页面贴标。

为什么模型少了一小块嘴部？

原始 CAD 的软嘴顶部没有可提取的保存显示网格，因此这一个零件未显示。15 颗舵机均已提取，包括嘴部 ID 34。

手机能看吗？需要联网吗？

支持现代浏览器的 WebGL。首次打开 3D 页需要下载约 20 MB 网格，建议使用 Wi-Fi。下载仓库后可在本地启动网页服务，离线查看。

模型与图纸

飞特版图纸由 机械行者Robo 建模整理，经 fanhao375 / microduck-replica-cad 发布。该设计基于 Pollen Robotics / MicroDuck 上游模型。

使用 v2.1 发布包 SolidWorks-FT2026-09-25 的原生装配变换和保存显示网格。本站增加了 ID 标注、交互查看和装配说明。
