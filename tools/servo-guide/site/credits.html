飞特 v2.1 装配模型

图纸作者：机械行者Robo。由 fanhao375 / microduck-replica-cad 发布，基于 Pollen Robotics / microduck_rl 上游模型重建和适配。

固定来源为 v2.1 发布附件 SolidWorks-FT2026-09-25.zip，顶层装配体为 00-microduck装配体-FT2026.9.23.SLDASM。

本站修改：提取原生装配变换及保存的显示网格，转换坐标轴和单位，加入舵机编号、名称及组件说明；省略没有保存显示网格的软嘴顶部。15 颗舵机均已提取。显示网格用于安装定位，不作为加工尺寸或校零姿态依据。

编号与使用范围

编号遵循 MicroDuck 项目的关节 ID，再按 CAD 的装配层级、左右位置和输出轴关联到实例。它是人工建立的装配注释，不是从你的舵机读到的 ID。原始实例变换、零件哈希和标注链保留在仓库的 site/model/。

本站不连接串口、不更改舵机 ID、不执行归零或运动。勾选记录仅保存于当前浏览器。本站无分析追踪脚本；网页由 GitHub Pages 提供，网络请求仍受 GitHub 的服务与隐私政策约束。
