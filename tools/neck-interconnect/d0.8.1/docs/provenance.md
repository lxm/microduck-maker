# 来源与整理范围

设计来源是维护者本地 `D0_8_1-pinfix-testpoints-20261101` 快照，2026-11-02 整理到 MicroDuck Maker。该版本复用原配胶壳线，采用修正后的 D/G 铜网、端口丝印及加大的通孔测试点。它是社区自制连接板，与官方颈部 PCB 没有等同或认证关系。

`source-manifest.json` 记录收录文件的来源相对路径、整理前后 SHA-256 和修改说明；`manifest.json` 记录当前实际交付文件哈希。原先的 ERC、DRC、针序、Gerber 和丝印检查记录放在 `validation/original/`，其中源板哈希指向整理前的装配参考板，不能直接拿它代替当前包的哈希。

本次没有改变铜层、焊盘、孔位、丝印或 Gerber。主 PCB、制造单板和两个固定孔封装仅移除了指向厂家舵机 STEP 的可选 3D 模型引用，厂家舵机 CAD 文件不在本次资料包内；[保持检查](../validation/package-preservation.json)记录了这项文本级比较。其余原文件按清单保留。历史生成器依赖其他试验版本，没有作为可独立重建脚本收录；后续编辑以本目录可编辑 KiCad 原文件为准。

PCB 板形与安装孔此前参考 HD-1910-C001 的厂家装配 STEP；50mm 轴距等装配假设沿用原设计，尚未完成当前实物版本与整机运动范围复核。板级 STEP 不包含舵机，原配胶壳／短线模型为维护者重建的示意包络，不是供应商原始精确 CAD；A2007WV-3P 简化模型参考 [CJT A2007 系列尺寸资料](https://www.cjt.com/upload/A2007.pdf)。J1–J4 复用原配件，没有确认独立采购料号。

原创 PCB、简化示意模型、校验脚本及说明按仓库 MIT 许可提供。该许可不授权第三方商标或未附带的厂家 CAD，也不表示连接器或舵机制造商对本设计背书。

后续通孔／贴片排母兼容试装方案没有放入本目录或制造 ZIP。需先确定具体端子、实际插接深度、塑壳与焊脚贴壳空间、接触稳定性及负载表现，再决定是否作为独立硬件版本收录。
