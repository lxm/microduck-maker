# 接线与装配

## 准备的物料

一片 D0.8.1 PCB、四组舵机原配 AMP2.0 三芯胶壳线、两只 **CJT A2007WV-3P**，以及与实际舵机壳体孔深匹配的固定螺钉。各组原配线保留胶壳与压接触点，只裁剪靠 PCB 的线端。板上没有需要采购的 J1–J4 标准直插排母。

[BOM](../bom.csv) 从原理图属性导出。J1/J3 与 J2/J4 因镜像封装分成两行，合计四组原配胶壳线；原配胶壳没有确认的独立采购料号，表中的 `NOT_IDENTIFIED_OEM_SUPPLIED` 表示复用原件，不能作为商品型号搜索。J5/J6 合计两只 A2007WV-3P。测试点不需焊接器件。

## 放置与截线

1. 断开电池，把 PCB 放到两只舵机的预定贴壳位置，确认板边、舵盘避让和四个固定孔自然对齐。PCB 不靠插头或线材垫起。
2. 把四只原配胶壳分别插入对应的舵机插座。先核对 [D／+／G](pinout-and-testpoints.md)，再逐根找出线端与对应 PCB 通孔，不以线色判断极性。
3. 按实际配合标记每根线的长度，再剪断、剥皮。让绝缘层止于 PCB 舵机侧，导体通过通孔，在外侧留适合焊接的小段。不要按示意模型统一剪固定长度，以免某些线拉紧或把板顶起。
4. J1–J4 的成品孔标称 Ø0.70mm、焊盘 Ø1.20mm，脚距 2.00mm。检查线芯和镀锡后的外径能够穿过；不要剪掉部分线股凑孔，也不要把大焊锡球硬压入孔内。

F 面是外侧，B 面是舵机侧；四组线由 B 面穿向 F 面，在 F 面焊接。J5/J6 连接器本体位于 B 面，焊尾穿板，在 F 面焊接。两个座的位置和方向保留原设计，凸台在 F 面正立视图的左边。

## 焊接顺序

确定长度后拆下 PCB／线束进行焊接，避免把烙铁热量持续传入舵机。先点焊定位一根线，检查线序和贴壳空间，再焊余下两根；四个端口依次完成。保留胶壳和原压接触点，焊接只发生在线材剪短后的 PCB 端。

检查焊点润湿、无连锡或散开的铜丝；舵机侧不能留会顶住后壳的大焊锡包。线材不承担结构固定，螺钉才用于固定 PCB。按实物孔深选螺钉，不以拧紧螺钉的方式强行消除板翘或顶壳。先分板并磨平邮票孔残边，再焊接、装配。

## 上电前后核对

- 各接口的 D 到 TP1、+ 到 TP2、G 到 TP3 应分别导通；D／+／G 三网之间不应短路。
- 逐一核对 J5/J6 外接线束另一端，特别是头部的降压输入。此板 + 直通电池，不能作为 Zero 3W 的 5V 输出。
- 装回后确认 PCB 自然贴壳、舵盘无擦碰、接头未受侧向顶压，线束在预期关节运动范围内没有拉扯或夹线。
- 初次上电先确认供电极性、电压及通信，再逐步增加负载，检查压降和接头、焊点、铜箔的温升。

3D 中胶壳与线端是简化示意，实际裁线、螺钉深度和运动干涉都应以样板为准。本版不包含任何 4.3H 贴片排母装配承诺。
