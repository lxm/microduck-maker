# 打板文件与参数

| 参数 | 单板 | 六联拼版 |
| --- | --- | --- |
| 版本 | D0.8.1 | D0.8.1，每大板六片 |
| 材料／层数 | FR-4／双层 | FR-4／双层 |
| 板厚／外层铜厚 | 1.6mm／每面 1oz | 1.6mm／每面 1oz |
| 包围尺寸 | 25.5×40mm | 94.5×96mm |
| 结构 | 无工艺边 | 3列×2行，5mm 工艺边、2mm 间隙 |
| 分板 | 无 | 铣槽＋NPTH 邮票孔，不是 V 割 |
| 阻焊／丝印 | 绿油／双面白字 | 绿油／双面白字 |
| 装配 | 裸板手焊 | 裸板手焊，先分板再装配 |

单板包围面积 10.20cm²，不等于扣除上下避让后的净板面积。六联按整块大板计数，例如五块大板得到三十片小板；已在文件内完成拼版，不再勾选平台自动拼版。

- [单板 ZIP](../fabrication/D0_8_1_1oz_single/MicroDuck_Neck_D0.8.1_1oz_single_25.5x40_PINOUT_CHECK.zip)／[参数文本](../fabrication/D0_8_1_1oz_single/下单参数.txt)
- [六联 ZIP](../fabrication/D0_8_1_1oz_6up/MicroDuck_Neck_D0.8.1_1oz_6up_94.5x96_PINOUT_CHECK.zip)／[参数文本](../fabrication/D0_8_1_1oz_6up/下单参数.txt)

每个 ZIP 包含十个文件：正反铜、正反阻焊、正反丝印、板框、PTH 钻孔、NPTH 钻孔及 gbrjob。ZIP 与旁边 `gerbers/` 文件逐个比对，整理时保持原字节和 SHA-256；文件名中的 `PINOUT_CHECK` 提醒装配前核对真实线束，不代表已经完成实物验收。

Gerber 预览中应能看到 `NECK D0.8.1`、J1–J6、每口 D／+／G 及 TP1–TP3。旧 D0.8 的 J1/J2 曾反接，不能使用其他来源的旧 ZIP 替代本目录文件。

此包不含钢网、贴片装配订单或替代排母的制造数据。1oz 为本版设计铜厚，实际线束、连接器与整机负载温升仍需样板验证。
