# 颈部舵机连接板

将两只颈部舵机的 DATA、电池电源与地汇接到一块 PCB，通过左侧两个插座连接下半身和头部，减少颈部独立线束。PCB 主体与舵机参考外壳齐边，直接贴壳安装，不设垫柱。

当前收录 **[D0.8.1 原配胶壳短线穿孔焊接版](d0.8.1/README.md)**。它使用舵机原配 AMP2.0 胶壳、原压接触点和剪短的原配线，线端穿 PCB 通孔，在外侧焊接。J5/J6 使用 A2007WV-3P。它是带检查记录的原型资料，不是已完成整机实物验收的成品设计。

后续通孔／贴片排母兼容试装版暂未收录。待具体端子的针型、插入深度、贴壳间隙及负载表现验证后，再单独发布；当前制造文件不包含其贴片焊盘。旧 D0.8 的 J1/J2 曾出现 D/G 反接，本目录只提供修正后的 D0.8.1，不能用旧包替换。

离线检查：

```sh
python3 tools/neck-interconnect/scripts/validate.py
```

该检查不需要 KiCad、不连接机器人，核对归档文件哈希、模型路径、制造 ZIP 与针序检查记录。编辑电路后还需在 KiCad 中运行 ERC、DRC 和原理图一致性检查，重新生成制造文件。
