# D0.11 焊线装配参考图

这两张图来自维护者本地 `D0_11-7343-20261030` 版本，保留原图片内容与文件名，用于展示大焊盘短线搭焊、原配 AMP2.0 胶壳和两个 A2007WV-3P 的装配效果。

- [cap-front.png：正面](cap-front.png)，包含 C1 电容示意模型。
- [cap-back.png：背面](cap-back.png)，展示原配胶壳和两个外接插座。
- [原图来源及 SHA-256](source-manifest.json)。

两图均为相同尺寸、背景与正投影视角的 KiCad 渲染。背面观察时左右镜像，凸台出现在右侧。

**当前仓库可下载的 PCB 和 Gerber 是 [D0.8.1 穿孔焊接版](../../d0.8.1/README.md)**，并非图中的 D0.11 大焊盘电容版。D0.8.1 不包含图示的大搭焊焊盘和 C1 电容封装，其实际正反面见版本说明中的裸板图。本次只补充这组参考图，没有更换 PCB、BOM 或打板文件。

图中的电容和胶壳／线材是装配示意，不能用于确认具体器件的电气适用性或实物配合。原创渲染图适用仓库 MIT 许可。
