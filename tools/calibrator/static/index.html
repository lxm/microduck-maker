WORKBENCH GUIDE

操作说明与参数

标定顺序

检查环境与串口 → 进入标定 → 选关节 → 手动摆正 → 稳定采样 → 保存 → 可选保持 → 下一颗。采样约 1 秒，保存仅修改选中舵机的 EEPROM 零位，不自动使能。嘴部需分别记录自然闭合与舒适张开。

机械零位与 HOME

机械零位向身体与头颈 14 颗直接发送 2048。HOME 使用模型站立参考角度，按身体方向 −1 换算为 2048 − 角度 × 4096 / 360，不再次叠加 EEPROM 偏移。两者都使能并保持，嘴部 ID34 不参与。HOME 不用于采样保存零位，也不代表能自行站稳。

保持与断力

整机姿态沿用舵机原有 P/D，扭矩寄存器上限 600/1000，保留原有更低上限。单颗保持采用身体 P5/D20、嘴 P10/D20，上限 300；可能不足以承担整机重量。释放后恢复进入工具前的参数。

躯干固定，双腿悬空，头颈留出活动空间。页面心跳中断约 10–12 秒时尝试全部断力；串口失联时不能保证成功。标定期间手柄服务暂停，网页断力不是硬件急停。
