这是针对 HD-1910 的独立社区工具。Python 访问电脑的 USB 串口，浏览器显示界面，无需 Windows、Wine 或浏览器串口授权。

01 / 连接

先接 USB，再接舵机电源

刷新端口，选择 /dev/cu.*，HD-1910 默认波特率为 1000000。点击「连接设备」。无硬件时选择演示设备。

02 / 搜索

搜索并选择一颗舵机

默认搜索 ID 0–35，可调整至 0–253。打开连接、搜索和选择舵机只读取，不开启扭矩或写运动目标。

03 / 微调

使能，再用 ±1° 检查方向

托住关节，点击「在当前位置使能」。编辑目标后点击「写入目标」才运动。超过当前位置 10° 会再次确认。

04 / 校零

关闭扭矩，摆到模型零位

摆正后点击「当前位置设为零位」。完成后保持断扭；先验证单颗掉电保存，再检查完整活动范围。旧姿态需要重录。

参数、备份与结束操作

在「参数与编程」读取参数，保存 JSON 可下载完整快照；载入 JSON 只显示差异，不自动覆盖。EEPROM 修改前自动备份，写入后回读并重新上锁。

自动备份：~/Library/Application Support/MicroDuck FD/。演示备份带 demo- 前缀；页面通信日志显示具体路径。CSV 导出与 JSON 保存由浏览器下载。

结束时先托住机身，再关闭当前舵机扭矩或点击「全部已搜索舵机卸力」。确认反馈后断开连接。关闭网页、串口或服务都不会自动卸力；终端按 Ctrl+C 结束服务。

适用范围与常见问题

支持哪些舵机与功能？

针对型号值 7946 的 HD-1910，位置模式 0/4。其他型号仅开放读数与卸力。不含固件升级、.xdat 导入、群控或自动扫动。HD mode 4 的速度、加速度及电流不能作为可靠保护，校零也不能消除机械干涉。

找不到串口或搜索不到设备

检查 USB 数据线、舵机供电、TTL 总线接线与波特率；关闭占用同一串口的其他程序，再刷新端口。没有搜索结果时扩大 ID 范围。确认转接器型号后使用对应的 macOS 驱动。

为什么按钮是灰色的？

先连接、搜索并选择设备。写目标须有新鲜反馈、HD-1910 位置模式和已开启扭矩；校零、改 ID 和参数写入须关闭扭矩。通信中断后暂停写入，恢复反馈或重新搜索后再操作。

演示验证和实机验证有什么区别？

演示验证界面与模拟寄存器流程，不证明真实固件兼容性或机械安全。当前版本尚未完成实机验收，请先对单颗验证。
